# Flow State

Application personnelle de Nathan Boyer : le programme quotidien (lois, compétences de la semaine, bilan du soir, revue du dimanche).

Les données restent uniquement sur le téléphone (stockage local du navigateur). Rien n'est envoyé sur un serveur.

Installation sur iPhone : ouvrir le lien dans Safari, bouton Partager, puis « Sur l'écran d'accueil ».
